# QR & Barcode Studio Pro

Aplicación de escritorio para Windows para leer y generar códigos QR y códigos de barras desde la pantalla, archivos o cámara.

## Descarga

Los instaladores con versión se publican en la sección [Releases](https://github.com/NocturneLegion/qr-barcode-studio/releases) de este repositorio.

## Requisitos

- Windows 10/11
- Cámara web (solo para escaneo por cámara)
- No requiere instalación de Python ni dependencias (instalador independiente)

## Características

- Escaneo de QR y códigos de barras desde pantalla, archivos de imagen o cámara
- Generación de códigos QR y de barras (Code128, Code39, EAN-13, EAN-8, UPC-A, ITF)
- Idiomas: Español, Inglés y Francés

## Desarrollo

Requisitos: Python 3.13.

```bash
pip install -r requirements.txt
python build_exe.py
```
